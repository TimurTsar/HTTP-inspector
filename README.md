# HTTP-inspector
a beginner Python-project with HTTP-requests

Features:
This program asks user URL-address;
It sends GET-request to server;
Then it shows status code, headers and time;
If it's error, it will show it to user;

Instruments:
lan: Python
Lib: "requests" for HTTP-requests, "time" for counting time

How-to-use instruction:

Clone this repository:
- git clone REPOSITORY_URL

Install the required library:
- python -m pip install requests

Run it in Terminal:
- python main.py

Learning Objectives

This project helped me practice:
Python fundamentals.
Working with external libraries.
Sending HTTP GET requests.
Understanding HTTP responses and status codes.
Exception handling (try / except).
Measuring execution time.
